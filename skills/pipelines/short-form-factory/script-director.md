# Script Director — Short-Form Factory

## When to Use
Write the short-form script with MoneyPrinter-style per-sentence keyword tags for automated stock/AI visual matching.

## Process
1. **Sentence Breakdown:** Break the narration into tight, punchy sentences (2-4 seconds each).
2. **Search Term Tagging:** For every sentence, extract 1-2 concrete search terms (e.g. `"boiling hot pot"`, `"chili sauce splash"`).
3. **Delivery Cues:** Provide emotional acting directives for VoxCPM or speed/pitch modifiers for Edge-TTS.
4. **Validation:** Word count strictly budgeted within target duration at ~2.5-3.0 words/second.

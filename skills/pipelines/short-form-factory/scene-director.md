# Scene Director — Short-Form Factory

## When to Use
Design the 9:16 vertical scene layout, rapid cut pacing (2-4 seconds per visual), and safe-zone compliance.

## Process
1. **Vertical Framing (9:16):** Ensure visual subjects are centered in the 1080x1920 canvas.
2. **Safe Zone Awareness:** Keep critical text and UI elements away from the top 150px (status bar) and bottom 300px (TikTok/Reels UI buttons).
3. **Rapid Cut Rhythm:** Never hold a static visual for more than 4 seconds. Mix Ken-Burns zooms, pans, and cuts.
4. **Output:** Schema-valid `scene_plan` artifact.
